PoliteChat

PoliteChat is an interactive interface that explores how AI can transform blunt messages into more polite language. The system rewrites direct or harsh messages into more polite language, showing how digital tools could shape the tone of online conversations. The project reflects on how technology may mediate emotions, social behavior, and communication in digital environments.

The project uses a language model API to analyze user input and generate alternative responses.
